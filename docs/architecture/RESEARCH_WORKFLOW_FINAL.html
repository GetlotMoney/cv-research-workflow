GZSL 的四条实验路线

复

复现：验证论文或已有代码，编号 `repro-*`，不会产生子 Framework。

调

调参：改变配置，编号 `tune-*`，不会产生子 Framework。

消

消融：关闭或替换已有模块，编号 `ablate-*`，不会产生子 Framework。

创

创新：必须绑定 Idea，编号 `innov-*`；成功、确认并提交后才能晋级。

不会越过的边界

不提前创建个人实例 不提前创建五个空方向仓库 不提供 GZSL CPU 退路 不把原始数据复制进 Git 不把“信任外来代码”冒充操作系统沙箱 不接受手写两份相同成绩作为等价证明 不把合成调试结果当论文成绩 不让 PaperFlow 直接读取变化中的实验目录 不自动 push、投稿或发布
