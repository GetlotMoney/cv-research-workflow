# 科研工作流 V1.0 使用说明

## 1. 检查通用安装

```powershell
Set-Location 'D:\智能双流系统'
.\tools\install-research-workflow.ps1 -Check
```

看到下面这句话表示通用 Skill 和 GPU 环境已经同步：

```text
Research environment and shared Skill Junction are synchronized.
```

没有激活个人工作区时，系统只检查通用模板，不会偷偷创建用户目录。只有你明确决定开始个性化后，才进入下一步。

## 2. 建立个人工作区

先选择一个显示名称和一个英文短名：

```powershell
.\tools\instantiate-workspace.ps1 `
  -DisplayName "我的 CV 科研工作流" `
  -Slug "my-workspace"

.\tools\activate-workspace.ps1 -Slug "my-workspace"
```

英文短名只能使用小写字母、数字和短横线。已经存在的个人工作区绝不覆盖。

## 3. 重新启动

```powershell
& '.\停止工作流.bat'
& '.\启动工作流.bat'
```

打开 `http://127.0.0.1:18082/`，页面应显示刚激活的个人工作区。

## 4. 创建第一个 GZSL 仓库

在页面选择 GZSL，填写仓库名，例如 `my-gzsl`。仓库只会创建在：

```text
users\my-workspace\repositories\my-gzsl
```

另外五个方向尚未开放，因此不会创建空仓库。

六个方向的名称和状态都来自 `config/directions/catalog.json`。当前只有 GZSL 已开放；图像分类、目标检测、实例分割、语义分割和超分辨率都处于“尚未开放”状态。

## 5. 选择一种实验

创建实验时必须填写 `--route-contract`，也就是先约定这次比较允许改什么：

| 类型 | 用来做什么 | 必须写清什么 |
|---|---|---|
| 复现 | 检查已知结果能否重现 | 目标结果、允许误差、相同数据和评估规则 |
| 调参 | 只改变参数 | 允许改变哪些参数、搜索范围和停止条件 |
| 消融 | 关闭或替换一个组成部分 | 关闭哪个组成部分、关闭后的行为和比较指标 |
| 创新 | 检验一个新想法 | 绑定的 Idea、真实基线和最低提升要求 |

实验编号在整个仓库中唯一。创建实验后，系统会为它建立独立分支和 Worktree。

## 6. 登记数据

真实数据保留在你指定的本机位置。Git 只保存：

- 数据集名称和版本；
- 来源地址与许可证；
- 文件 SHA-256；
- 数据内容清单；
- 使用的划分。

原始数据和大型权重不会复制进仓库。

当前方向包接受的单个 NPZ 文件上限是 1 GiB。对外生成记录时不会写入本机绝对路径，避免把你的磁盘目录泄露出去。

## 7. 运行

先做小规模 GPU debug，确认代码、数据和指标链路正常；再用完全相同的配置与随机种子做正式 evidence Run。

一次完整运行依次完成：

```text
train → evaluate → infer → 保存日志与产物哈希
```

正式运行必须通过真实 CUDA 小计算，不能由外来代码自己声称“使用了 GPU”。

第一次运行后，配置与随机种子会冻结。系统会拒绝中途改配置后继续冒充同一次实验；如果确实要换条件，应新建实验。

## 8. 人工确认

运行结束不等于结果已经认可。你必须检查：

- 使用的代码提交；
- 数据和划分；
- 配置与随机种子；
- S、U、H 指标；
- 日志、权重和输出；
- 是否存在异常或数据泄漏。

创新实验还必须用 `--innovation-outcome accepted|rejected` 明确选择“接受”或“拒绝”，并写明结论。只有选择接受、完成上述人工确认并提交 Git 后，创新结果才能晋级成稳定子 Framework。

确认后系统才把结果标为可交付科研结果。论文阶段不在本说明中启动。

## 9. 接入外来 Framework

外来代码必须先放进个人 `inbox`，再按以下顺序处理：

1. 人工阅读来源和许可证。
2. 扫描训练、评估、推理和配置入口。
3. 修正组件与文件的对应关系。
4. 生成受控标准化草稿。
5. 明确确认代码可信后才允许给出 `--i-trust-this-code` 并执行。
6. 使用相同数据和划分真正重跑，不能手写两份相同成绩冒充等价检查。
7. 核对实际命令、输出文件哈希，并通过标准测试、中央 CUDA 检查和两名不同复核人的确认后，才登记为稳定 Framework。

信任确认不是操作系统沙箱，来源不明的代码不要运行。

## 10. 停止

双击：

```text
D:\智能双流系统\停止工作流.bat
```

停止服务不会删除仓库、实验、数据或日志。
