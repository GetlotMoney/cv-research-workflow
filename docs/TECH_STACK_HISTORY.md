## ENV-CORE-V1.0.1：环境也归入唯一系统目录

- 日期与状态：2026-07-29，已完成。
- 本次改的是哪个对象：PaperFlow Python 运行环境的位置和启动配置。
- 目标问题：旧 PaperFlow 环境是一个指向旧目录的 C 盘 Junction（目录链接），删除旧目录后入口随之失效。
